# Changelog

The full, always-current changelog lives on the [WordPress.org plugin page](https://wordpress.org/plugins/auto-repai-ai-content-generator/#developers). Highlights:

## 2.10.0 — August 2026

**Free**
- **Health Report** — printable GEO + accessibility report, unlimited, PDF from the browser.
- Pre-run **cost estimates** on batch actions.
- Cleaner result tables (direct "Available in Pro" links), assets load only on plugin screens, hardened sanitization and uninstall cleanup, expanded External Services documentation.

**Pro**
- **White-label reports** and the **EAA deep-dive** template (WCAG-mapped, with remediation plan).
- **GEO trend** — daily site score snapshots with a chart and 28-day delta.
- **WooCommerce catalog autopilot** and the **AI Product Advisor** storefront widget.
- **Settings export/import** (secrets never leave the site).
- **Knowledge Base semantic grounding** — AI-Reference posts + bulk indexing (hybrid retrieval).
- **Applied links archive** for the Internal Linker.

## 2.9.0

- Pro: AI Forms image/file uploads with vision models; a new Image-analysis template.
- Pro: Automations stock-photo featured images (Pexels/Pixabay, your keys).

## 2.8.0

- Pro: **Accessibility Repair AI** (free scanner + Pro one-click and autopilot repair).
- Pro: **Live chat takeover** — reply to chatbot visitors in real time from the dashboard.

## 2.7.0

- Pro: **Automations** (topic/RSS/URL creation, refresh rotation, auto internal-linking, comment replies) and **AI Forms**.
- Pro: monthly usage limits, event webhooks, WhatsApp hand-off.

## 2.6.0

- New design system across all screens, masked API keys, accessibility improvements.

## 2.5.x

- Initial WordPress.org release line: content generation, image generation, Auto Repair, Quick AI Edit, AI Visibility (GEO) + llms.txt, WooCommerce & alt-text scanners, Bulk Content, chatbot (Pro), importers (Pro), Workflow Studio (Pro), Lead Management (Pro), and the full security/GDPR baseline.
